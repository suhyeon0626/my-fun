# 나만 아는 재미를 소개해줄게 — 하늘 수집가

`index.html`을 더블 클릭하거나 브라우저로 끌어 놓으면 열립니다. 설치나 서버 실행이 필요하지 않으며, 모든 화면과 기능은 인터넷 없이 작동합니다. 폴더를 옮길 때는 `my-fun` 전체를 함께 옮겨주세요.

- `index.html`: 홈페이지 내용
- `style.css`: PC·모바일 반응형 디자인
- `script.js`: 사진 필터, 사진 확대와 닫기(Esc 지원), 촬영 미션
- `assets/`: 로컬 사진과 파비콘

갤러리 사진은 취미 소개를 위한 Unsplash 예시 이미지입니다. 직접 촬영한 사진으로 바꾸려면 assets의 파일을 교체하고 HTML의 사진 설명도 수정하세요.
